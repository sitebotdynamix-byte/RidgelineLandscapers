# Ridgeline Landscapes (sample site)

Files: index.html, styles.css, script.js, IMAGE-LOG.md.

1. Unzip and open index.html in a browser, or upload the files to any static host (Netlify, GitHub Pages, Cloudflare Pages).
2. The three photos load directly from Unsplash, so the page needs an internet connection to show them. To make the site work offline, download each photo from its source page (see IMAGE-LOG.md), put the files in an images folder, and change the img src values.
3. If an image fails to load, its figure hides itself so no broken box appears.
